# Human-Style-Writing

Human-like writing for **daily chat (DM/text)** and **social media posts/captions** (EN/中文/mixed).

## Scope
Hard constraint: **chat + social only**.

If asked for academic writing, news/press, legal/compliance, marketing copy, customer support macros, or work emails/reports, the skill should **redirect** by asking:
> Do you want this rewritten as (A) a DM/text message, or (B) a social post? If social, which platform?
